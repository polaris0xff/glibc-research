           target bin/.meld-wrapped is a PYTHON SCRIPT. ReadWrapper returns
           nothing for a script and elfx.IsELF is false, so

           statement that nix cannot do Python.

           GTK — with ZERO host shared objects. The field grades GTK

        ⛔ WHAT BLOCKS galculator IS A HARDCODED ABSOLUTE STORE PATH:
             Couldn't load /nix/store/<hash>-galculator-2.1.4/share/...
           The file IS in the bundle. XDG_DATA_DIRS points at the bundle and
           serves every app that LOOKS UP its data; it cannot serve one with
           the path baked into its .rodata.
        ⭐ SO THE REMAINING GAP IS TOOLING, NOT CAPABILITY — T-081, whose
           entry names "hardcoded paths" verbatim. That is the label
           T-080's guarantee requires, and it is earned here rather than
           asserted.
