THE QUESTION (T-066 route A): an allowlist chooses which PATHS to carry.
It cannot remove a dependency a library DECLARES -- b.integrity() asserts
every DT_NEEDED resolves inside the bundle. So the bytes reachable ONLY
through an edge a `-mini` REBUILD deletes are the bytes no allowlist can
reach. That is the ceiling.

THE INSTRUMENT: `pgb bundle sweep --cut FROM=>TO` drops the edge from the
graph walk and from the soname string scan, and resolves the target to a
FILE so every name for it is cut. Nothing on disk is modified.
