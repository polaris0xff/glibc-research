=== what this means for the matrix ===
Arch publishes amd64 only. Upstream Arch does not support aarch64;
Arch Linux ARM is a SEPARATE project with its own package set and its
own build of glibc.

So this project does not label an aarch64 build `archlinux`. The
planner renames the distribution to `archlinuxarm` on that
architecture (crates/alloc-bench/src/plan.rs, effective_distro), and
the two never share a table row.

=== what this probe cannot tell you ===
- whether the published image for an architecture actually WORKS;
  a manifest entry is a claim of availability, not of function.
  images/*.Dockerfile building successfully is that evidence.

RESULT: exit 1 ON PURPOSE. A gap is present and is documented above.
If a future run exits 0, upstream has started publishing the missing
architecture and images/arch.Dockerfile's substitution can be retired.
